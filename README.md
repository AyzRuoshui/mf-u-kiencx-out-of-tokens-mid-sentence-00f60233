## Overview

A Node.js 22 (`program/v1`) entry that outputs a single-line, <=140-character error message displayed by an AI agent when it runs out of tokens mid-sentence.

## Usage

```bash
node main.ts
```

By default, writes to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Supports `--out <file>`, `-o <file>`, `--output <file>`, and `--out-dir <dir>` overrides for local verification.
